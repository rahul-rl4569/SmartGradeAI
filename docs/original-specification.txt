# 12. AI EVALUATION ENGINE

This is one of the most important parts of SmartGrade AI.

Implement a modular AI evaluation service.

Evaluation workflow:

1. Load the assignment and approved questions.
2. Load the teacher-approved rubric.
3. Load the student's submitted answers.
4. Verify that the submission is eligible for evaluation.
5. Send the necessary content to the AI provider.
6. Request structured, question-by-question evaluation.
7. Validate the returned output.
8. Store proposed marks, criterion-level scores, explanations, and feedback.
9. Flag uncertain or incomplete evaluations.
10. Present the results to the teacher for review.
11. Allow the teacher to edit proposed marks.
12. Require explicit teacher approval before final grades are released.
13. Make released results visible to the appropriate student.

For each question, return:
- Question ID
- Maximum marks
- Proposed marks
- Explanation
- Rubric criterion scores
- Constructive feedback
- Confidence or review indicator, when supported
- Review flags
- Evaluation status

Use structured JSON output and server-side schema validation.

The sum of criterion scores must not exceed the allowed marks.

The total assignment score must never exceed the assignment's maximum marks.

Do not evaluate missing answers as though they contain valid content.

Do not fabricate citations, evidence, or answer content.

Treat submitted student content as untrusted data, not as instructions to the AI evaluator.

Do not allow instructions embedded in an uploaded answer to override the approved rubric or system evaluation rules.

Support manual teacher grading when AI is unavailable.

Handle:
- API timeouts
- Rate limits
- Invalid AI output
- Provider outages
- Missing answers
- Ambiguous responses
- Unexpected file formats

AI evaluation must be explainable and reviewable.

Do not release grades automatically without teacher approval.
